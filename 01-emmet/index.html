01-Emmet

Plugin for faster HTML and CSS coding.

01-child >

Creates child elemnets (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-subling +

Creates subling element.

Example:

header+section+footer ↔️

Result:

<header></header> <section></section> <footer></footer>

03-multiplication *

repeats elements multiple times.

Example:

ul>li*5 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-class .

creaters a class attribute.

Example:

div.important ↔️

div.danger ↔️

Result:

<div class="important"></div> <div class="danger"></div>

05-clases ...

Creates multiple class attributes.

Example:

div.red.green.blue ↔️

Result:

<div class="red green blue"></div>

06-idemtification #

Creates an ID attribute.

Example:

menu#cod123 ↔️

Result:

<menu id="cod123"></menu>

07-text {}

Inserts text content.

Examples:

div{volver} ↔️

click here ↔️

Result:

<p>lorem ipsum dolor</p> <a herf="">click here</a>

08-custom attribute []

Creates custom attributes.

Example:

input[type=number] ↔️

Result:

<input type="number">

09-Item Numbering $

Adds consecutive numbers.

Example:

ul>li.option$$*2 ↔️

Result:

<ul> <li class="option01"></li> <li class="option02"></li> <li class="option03"></li> </ul>

10-Reverse Numbering @

Inverts numbering order.

Example:

ul>li.num$@-*3 ↔️

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.num$@3*2 ↔️

Result:

<ul> <li class="num3"></li> <li class="num4"></li> </ul>

12-Climb Up ^

Moves up one level.

Example:

section>articicle>div^p ↔️

Result:

<section> <articicle> <div></div> </articicle> <p></p>
